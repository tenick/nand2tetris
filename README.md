# Flappy Bird - Nand2Tetris Edition

A reimplementation of **Flappy Bird** built entirely in the **Jack programming language**, running on the Nand2Tetris Hack computer.

![Flappy Bird Demo](https://github.com/user-attachments/assets/05f2680a-e397-4d7b-a624-6699ceaed0bc)

## Features

* Start menu
* Difficulty selection
* Procedurally generated pipes
* Collision detection
* Scoring
* Game-over and restart functionality
